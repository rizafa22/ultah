# 💖 Web Ucapan Ulang Tahun & Surat Spesial Interaktif

Website interaktif spesial ulang tahun yang dirancang dengan alur cerita 6 langkah yang romantis, animasi halus, musik ambient, dan efek visual confetti.

---

## ✨ Fitur Utama

1. **Langkah 1 (Kotak Hadiah):** Kotak kado dengan animasi goyang (*shake*). Ketuk kado atau tombol untuk membuka.
2. **Langkah 2 (Kotak Misteri Terbuka):** Tutup kado terangkat dengan koin emas & percikan confetti.
3. **Langkah 3 (Surat Dari Hati):** 
   - Amplop tertutup bersegel pita stempel "*POST LOVE*".
   - Saat segel dibuka, muncul surat romantis bernuansa tulisan tangan (*handwritten style*) dengan nama **Zahra Cantika Putri** dan pengirim **R**.
4. **Langkah 4 (Galeri Kenangan):** Foto polaroid dengan selotip (*washi tape*), miring natural, dan tombol *like* interaktif.
5. **Langkah 5 (Tiup Lilin):** Kue ulang tahun 2 tingkat dengan 3 lilin menyala berkedip (*flickering flame*). Saat tombol ditekan, api padam dengan animasi asap realistis dan letusan *confetti* meriah!
6. **Langkah 6 (Penutup & Balasan WA):** Ucapan tulus terakhir dan tombol langsung untuk membalas ke WhatsApp pasangan.
7. **🎵 Ambient Music Box:** Synthesizer nada kotak musik romantis otomatis yang dimainkan langsung di browser (*Web Audio API* — tidak butuh file MP3 eksternal).
8. **⚙️ Tombol Edit Teks Langsung:** Tersedia tombol *Edit Teks* di pojok kanan atas untuk mengganti nama penerima, nama pengirim, nomor WhatsApp, dan isi surat secara langsung tanpa coding!
